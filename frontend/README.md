# SIS Esthetics – фронтенд за резервации

Next.js 15 (App Router) + TypeScript + Tailwind CSS 4 + Motion. Говори с Django API-то от главната папка.

## Страници

- `/` – начална страница с бутон „Запази час“
- `/rezervacia` – резервация в 4 стъпки: услуги → специалист (и „едновременно“) → дата и час → данни
- `/rezervacia/<token>` – преглед на резервацията, добавяне в календара (.ics) и отказ до 24 ч. преди часа
- `/uslugi` – услуги и цени по категории
- `/za-nas` – екипът със снимки и представяне
- `/statii`, `/statii/<slug>` – статии (филтър по таг: `?tag=`)
- `/kontakti` – адрес, телефон, работно време, условия при резервация
- `/obshti-usloviya`, `/poveritelnost` – текстовете от админа (Съдържание → Страници)
- `/vhod` – вход за клиенти: с Google или с код по имейл
- `/profil` – профилът на клиента: предстоящи часове, история, данни, съгласия, изтегляне и изтриване на данните
- `/profil/saobshtenia` – съобщения със салона
- `/personal` – дневният календар за екипа в стила на Studio24, `/personal/vhod` – вход за персонала
- `/personal/saobshtenia` – съобщенията от клиенти; „Карта на клиента“ от часа в календара показва псевдоним, общи и
  лични бележки, посещения и разговора

Публичните страници са в `src/app/(site)/` със заглавката и долната част на сайта; `/personal` е без тях.

Страниците със съдържание се рендерират на сървъра с пресни данни от Django (`BACKEND_URL`). Данните се
зареждат в базата с `python manage.py import_site_content`. Снимките на екипа идват през `/media/*`.

Часовете винаги се показват във времето на салона (Europe/Sofia), независимо от устройството.
Поддържа светла и тъмна тема и може да се инсталира като приложение (PWA manifest).

## Локално

```bash
# 1) backend на http://localhost:8000 (виж README-то в главната папка)
# 2) фронтенд:
cd frontend
npm install
npm run dev          # http://localhost:3000
```

`/api/*` се пренасочва към Django (`BACKEND_URL`, по подразбиране `http://localhost:8000`), така че не е нужен CORS.

Проверки: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

## Структура

- `src/lib/api.ts` – типизиран клиент за API-то
- `src/lib/booking-state.ts` – състоянието на резервацията (reducer)
- `src/lib/format.ts` – цени, продължителност, дати и часове на български
- `src/components/booking/` – стъпките, обобщението и страницата за управление
- `src/lib/staff-api.ts`, `src/lib/calendar.ts`, `src/components/staff/` – календарът за персонала
